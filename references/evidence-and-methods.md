# 证据与研究方法

## 证据记录

对每个重要来源或发现，尽可能记录以下信息：

| 字段 | 记录内容 |
|---|---|
| 来源 | 数据集、访谈、评论、报告、产品页面或其他来源；有路径或网址时一并记录 |
| 日期 | 采集、发布或观察的时间段 |
| 对象 | 这项证据所代表的人群或对象 |
| 样本量 / 覆盖范围 | 样本数、记录数或其他明确的覆盖指标；未知时注明“未知”或“未采集” |
| 方法 | 招募、采集、抽样或分析方法 |
| 招募渠道 | 面板、社群、客户名单、公开评论等来源，以及筛选条件 |
| 证据类型 | 观察到的行为、参与者陈述、公开说法、研究者解读或建议 |
| 来源关系 | 原始材料、转写、摘要、分析报告或综合报告；是否与其他材料重复或派生 |
| 局限 | 偏差、缺失、访问受限、子组样本过小、来源过期或来源不明等 |

不要推测未知值。参与者原话应与研究者编码或解读分开。产品公开宣传应与独立观察到的表现分开。

## 可信程度的判断

说明结论可信程度时，写出判断依据，不必压成一个总分。可检查：

- 来源是否接近原始记录，关键处理步骤是否可复核。
- 方法是否适合回答当前问题，测量是否清楚且一致。
- 样本是否匹配目标人群和使用情境，招募与无应答偏差是否已知。
- 证据是否来自相互独立的来源，或只是同一数据的不同报告。
- 是否存在反向证据、缺失数据、替代解释或尚未验证的假设。

证据较弱不代表没有价值；可将其标为探索性信号，并明确它适合支持什么决策、还需要什么验证。

## 综合多种证据

- 查找证据之间的一致、分歧，以及可能推翻当前主要解释的材料。
- 未说明可比性依据时，不要合并不同人群或分母的数据。
- 合并不同波次或渠道前，先确认测量定义、问卷版本、目标人群、时间窗和纳入规则可比；分别保留各来源的有效样本数和题目级分母。
- 记录跨研究样本是否重叠。若问卷参与者又接受访谈，这是关联式混合研究，不能称为两个独立样本的独立验证。
- 同一数据生成的原始表、摘要、个案报告和综合报告属于同一证据链，不能按文件份数增加证据权重。
- 记录数量更多，不代表来源一定更有代表性或更可靠。
- 两个有不同招募偏差的样本方向相近，只能说明这些样本中的结果方向相近；除非抽样和分析支持总体推断，不要据此宣称市场代表性或独立验证。
- 自我选择的评论样本中反复出现某个主题，只能说明该来源中存在这一信号，不一定代表整个市场的发生比例。
- 用户表示有意愿、给出概念评分或偏好某项功能，并不能证明其会购买、采用、留存或愿意付费。
- 将建议视为不确定条件下的决策，而不是直接测量结果。

## 定量结果解释

- 说明百分比的分母，并为子组结果标明样本量。
- 结合抽样和招募限制说明估计结果。研究设计不支持时，不要使用虚假的精确度。
- 根据量表、研究问题、样本和统计假设选择汇总指标与检验方法。没有适用于所有研究的固定李克特指标组合或统一样本量门槛。
- 使用综合得分前，说明指标是否可比、权重由谁设定、权重为何适用，并检查结论是否会随权重变化。未经解释，不要把不同构念任意相加成一个优先级总分。
- 如果研究设计不能支持因果推断，不要把相关关系说成因果关系。
- 子组样本过小或抽样过程不清楚时，应标为探索性结果，或不对该子组下结论。
- 注意力检测题通过、作答时间合理或数据清洗通过，只能说明部分数据质量检查结果，不能消除招募偏差、需求暗示或代表性问题。
- 问卷应做预测试；将实际完成时长、弃答、缺失、直线作答和参与者反馈与预期时长对照。检测题通过率高不能单独证明问卷没有疲劳或测量偏差。
- 使用概念视频或产品刺激物时，记录素材、呈现顺序和理解检查。概念新奇感、感知有用性和购买意向分别报告，不当作真实任务表现。

## 定性结果解释

- 用具体的过往事件、情境、替代做法、后果和决策因素支撑主题。
- 按研究问题区分现有用户、曾使用后停用者、潜在用户和未接触品类者；这些群体回答的问题不同，不要求每项研究都覆盖全部群体。
- 只有在来源允许使用时，才准确保留有价值的原话；有定位信息时一并记录。
- 说明主题形成方式，并呈现重要例外或相互矛盾的陈述。
- 没有明确依据时，不要宣称主题已饱和、具有普遍比例或能代表整体人群。

## 结论措辞

优先使用范围明确的表述：

- “在本研究访谈的 18 位参与者中……”
- “在这批评论样本中，反复出现的抱怨包括……”
- “数据与该假设一致，但尚不足以证明……”
- “由于尚未采集……，这一点仍待验证。”

如果证据不支持，避免使用“用户都想要”“市场已经证明”或“大多数客户”等无边界说法。

## 评论与公开材料

- 记录产品、平台、采集时间窗、评论数量、筛选条件、去重方法和评分范围。说明样本是否只包含主动评价者或负面评价。
- 多标签编码时，说明一条评论可进入多个主题；主题数之和可能超过评论数。评论提及率不等于问题发生率或全体用户比例。
- 若目标是完整的用户价值分析，不要只看差评；根据可获得的数据说明正面、中性和负面评论各自的覆盖情况。
- 公开报告或仓库前，移除直接身份信息并检查职业、地区、时间、设备经历等组合是否可能识别个人。未经授权，不公开录音、逐字稿、个案问卷或原始评论数据。
