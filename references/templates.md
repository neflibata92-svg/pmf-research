# PMF 调研模板

根据研究问题调整以下结构。删除不适用字段；未知信息应明确标注，不要猜测补齐。

## 调研简报

```markdown
# 调研简报
- 产品 / 概念：
- 需要支持的决策：
- 目标客户与使用情境：
- 市场 / 地区 / 时间范围：
- 核心研究问题：
- 已有证据及来源路径：
- 证据缺口与假设：
- 建议方法及其适用理由：
- 抽样 / 访问 / 隐私限制：
- 交付物与受众：
- 待确认问题：
```

## 证据卡

```markdown
### 发现或来源：[简短标题]
- 来源 / 定位信息：
- 日期或时间段：
- 对象与样本量 / 覆盖范围：
- 方法：
- 招募渠道与抽样方式：
- 样本关系：是否与其他波次、研究或材料重叠；哪些报告由本来源派生：
- 证据类型：观察到的行为 / 参与者陈述 / 公开说法 / 研究者解读
- 证据成熟度：问题发现 / 概念评价 / 真实任务 / 重复使用 / 购买留存 / 商业可持续性
- 可以支持什么：
- 不能证明什么：
- 反向证据或冲突：
- 局限：
- 可信程度及判断依据：来源质量、方法适配、样本相关性、独立性、偏差与反向证据
```

## 决策摘要

```markdown
# PMF 调研摘要
## 决策与范围
## 证据支持的结论
## 按研究问题整理的证据
## 反向证据与分歧
## 采用与真实任务信号
## 购买或付费信号
## 留存与持续价值信号
## 假设与未知项
## 局限
## 建议决策或下一项验证
## 来源清单
```

## 样本与数据口径记录

```markdown
### 样本说明
- 目标人群及纳入 / 排除条件：
- 招募渠道、时间与地区：
- 邀请人数 / 完成数 / 有效样本数（如可得）：
- 各题实际作答数与缺失值处理：
- 剔除规则及剔除数量：
- 是否复访、样本是否与其他来源重叠：
- 多选题、权重、加权或合并口径：
- 与其他来源的可比性及差异：
- 原始数据到报告 / 摘要的来源沿袭：
```

## 交付前检查

- [ ] 已明确待支持的决策和目标人群。
- [ ] 重要结论可以追溯到来源证据或可复核的分析。
- [ ] 适用时已说明样本量、时间段、分母和数据剔除方式。
- [ ] 已记录招募渠道、题目级样本数、样本重叠及派生材料关系；未知项已标注。
- [ ] 已区分观察、参与者陈述、研究者解读和建议。
- [ ] 已说明证据成熟度；未把概念兴趣当成真实任务、重复使用或购买证据。
- [ ] 已呈现矛盾证据和负面案例。
- [ ] 已区分一致、互补、矛盾、单一来源和不可直接比较的结果。
- [ ] 没有把口头意愿写成已观察到的购买或持续使用。
- [ ] 已说明未知信息和局限；没有编造数值、原话或来源。
- [ ] 建议已说明依赖哪些证据和假设。
- [ ] 可信程度附有判断依据，没有用无解释的总分代替分析。
- [ ] 团队设定的目标或门槛与实际研究发现分开标注。
- [ ] 对外分享前已移除个人身份信息、未经授权的原话和受限原始材料。

## 脱敏示例

以下仅演示记录方法，不代表真实用户研究结论：

```markdown
### 发现：概念兴趣尚不能说明任务价值
- 来源：假设性概念访谈；具体来源和样本信息应按实际研究补充
- 证据类型：参与者对概念的陈述
- 证据成熟度：概念评价
- 证据关系：单一来源；目前没有独立行为证据
- 可以支持什么：该概念值得进入任务测试
- 不能证明什么：用户能完成目标任务、会持续使用或愿意付费
- 下一步：使用可操作原型观察目标用户完成任务，并记录求助、放弃和替代方案
- 可信程度及判断依据：探索性；样本与方法尚不足以支持行为或总体推断
```
