# PMF 证据成熟度与交叉验证

本框架用于说明证据能支持到什么程度、下一步应验证什么。它是便于讨论的工作阶梯，不是 PMF 的权威定义、评分表或通用通过标准。不同产品、客户、销售周期和风险需要不同证据。

## 证据成熟度工作阶梯

| 层级 | 典型证据 | 可以支持的判断 | 仍需谨慎的地方 |
|---|---|---|---|
| 问题发现 | 过往经历、现有替代方案、问题发生情境及影响 | 某类人群可能遇到某个问题；问题值得进一步验证 | 回忆和表达不等于问题频繁、优先级高或愿意改变 |
| 概念评价 | 对明确概念、原型或价格呈现的理解、兴趣和选择 | 概念是否易懂、哪些价值主张引发兴趣或疑虑 | 假设性反应不能证明实际使用、付费或市场规模 |
| 真实任务测试 | 用户在可代表实际情境的任务中完成或放弃操作，记录过程和阻碍 | 方案能否帮助用户完成任务、关键摩擦在哪里 | 一次受控测试不代表长期自然使用或广泛人群表现 |
| 重复使用 | 在真实情境中跨时段回访、持续使用或主动返回 | 价值是否可能持续，哪些因素影响留存 | 短期试用、提醒驱动使用或小样本仍不足以说明长期留存 |
| 购买或付费 | 实际购买、签约、付费转换、续费或复购及其背景 | 用户或组织是否愿意承担真实成本 | 区分补贴、试点合同、报销、渠道影响和自然需求；一次交易不代表持续价值 |
| 留存与持续价值 | 持续使用、续约、复购、主动返回，以及取消、退款等行为 | 用户是否持续从方案中获得价值 | 结合观察周期、使用情境和提醒因素解释；留存与付费应分别报告 |
| 商业可持续性 | 可重复获客、交付成本、毛利、销售周期、支持负担等 | 需求是否可能支持可持续交付和增长 | 需结合业务模式、时间窗口、客户集中度和可靠经营数据 |

不要把阶梯误读为所有项目都必须逐级通过的闸门。购买和留存是不同维度，具体顺序也会因产品类型、销售周期和使用频率而不同。高风险决策可能需要更多验证；早期探索可以停留在较低层级。结论应同时写明目标人群、情境、证据日期和未覆盖的关键环节。

## 跨来源综合矩阵

| 主题 / 研究问题 | 来源及样本 | 共同发现 | 互补发现 | 矛盾或反例 | 可比性与来源关系 | 当前判断及下一项验证 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

给每项证据标记一种关系，避免强行合并：

- **一致**：不同来源对相近问题给出方向相符的信号；仍须检查来源是否独立、样本是否重叠。
- **互补**：来源回答同一主题的不同部分，可以拼出更完整的解释，但不是重复验证。
- **矛盾**：结果方向或解释不一致。先检查人群、情境、时间、问题措辞、渠道和分母，再决定是否分群或补充研究。
- **单一来源**：当前只有一项来源支持。报告为待验证发现，不包装成稳健结论。
- **不可直接比较**：构念、口径、样本、时间或测量方式不同。并列展示并解释差异，不做未经说明的加总或排名。

## 样本关系与来源沿袭

1. 为每份原始数据和派生材料记录唯一来源标识、采集时间、招募渠道、研究对象、纳入规则和数据处理方式。
2. 标记受访者是否重叠、不同波次是否复访，以及报告、图表、摘要是否由同一数据集派生。派生材料不能算作独立佐证。
3. 多个招募渠道或多个研究方法可以扩展观察角度，但不会自动使样本具有代表性，也不等于独立重复验证。
4. 样本数若在报告间不一致，先核查有效样本定义、剔除记录、缺失值和题目级作答数；未能解释时保留差异并标为未核实。
5. 问题级百分比须说明分母及多选规则。合并样本前确认量表、题目、招募、时间与目标人群足够可比。

## 设计下一项验证

优先选择能区分关键解释的最小研究：

- 把“用户喜欢概念”拆成可观察任务，记录完成、求助、放弃、耗时和替代方案。
- 对重复使用假设，设置有意义的观察周期和回访方式，区分自然回访与研究提醒造成的使用。
- 对付费假设，尽可能观察真实价格、真实购买或续费行为，并记录折扣、报销、试点和渠道条件。
- 对分群差异，预先写明可行动的分群假设，避免事后只挑选看起来积极的子群。
- 把目标指标、样本量和决策门槛标成团队待设定的验收标准；与实测结果分开报告。除非方案明确提供依据，不把经验阈值说成行业标准或研究发现。

验证计划至少说明：要区分的假设、目标人群和情境、观察信号、招募与样本限制、时间窗口、停止或继续规则、隐私处理及结果如何改变决策。
